# OwnAPI 公开站点与用户看板动效设计

日期：2026-08-31

## 目标

在保留 OwnAPI 现有黑白、克制、专业视觉语言的基础上，为公开站点和普通用户登录后的看板加入有目的的动效。动效用于建立层级、解释状态变化和确认操作，不以持续运动或炫技作为卖点。

## 范围

包含：

- 公开首页、Models 列表与详情、Docs、法律页面以及公共导航。
- 普通用户 Dashboard、Usage、Keys、Subscriptions、Payment、Profile、Available Channels 和登录后 Monitor。
- 公共按钮、筛选器、卡片、弹窗、Toast、复制操作、加载状态和图表等共用组件。

排除：

- 所有管理员页面和管理员全局监控。
- 大型 WebGL 背景、鼠标光标跟随、强磁吸、持续旋转、重度视差和纯装饰性粒子。
- 任何会推迟首屏可交互时间、阻塞 API 请求或降低表格操作效率的动画。

## 方案选择

### 采用：克制的系统级动效

由少量全局 motion tokens、可复用 Vue transition、进入视口指令或 composable，以及局部状态反馈组成。公开页面允许有限的氛围动效；用户看板只采用功能性动效。

这一方案适合 OwnAPI：它保留专业感，也能让页面摆脱静态模板感。2026 年常见的微交互、滚动出现和动态状态反馈会被提炼使用，但不照搬高饱和 maximalism 或复杂 3D 趋势。

### 未采用：强表现型营销动效

包括大面积 kinetic typography、强视差、鼠标追踪和 WebGL。视觉冲击更大，但与 OwnAPI 当前极简风格不一致，移动端和低性能设备风险较高。

### 未采用：仅补几个 hover

成本最低，但不能改善页面进入、筛选重排、状态反馈和图表加载等关键体验，整体仍会显得不连贯。

## 动效原则

1. **有因果**：用户操作或内容进入视口后才发生，避免无缘由持续运动。
2. **短而轻**：微交互 120–200ms，中型组件 200–300ms，公开页面分层出现最多 450ms。
3. **少位移**：常规位移 2–24px；不让内容从屏幕外飞入。
4. **优先性能**：优先动画化 `transform` 和 `opacity`；避免持续修改布局属性。
5. **一次性氛围**：首屏和区块出现只执行一次；返回页面时不反复强制播放。
6. **不阻塞交互**：视觉过渡与数据请求并行，按钮反馈必须立即开始。
7. **尊重无障碍**：`prefers-reduced-motion: reduce` 下取消位移、缩放、计数和路径绘制，只保留必要的即时淡化或状态切换。

## Motion tokens

在前端全局样式定义语义化变量，供 CSS 和 Vue transition 共用：

- `--motion-instant: 120ms`
- `--motion-fast: 160ms`
- `--motion-base: 220ms`
- `--motion-slow: 320ms`
- `--motion-hero: 450ms`
- `--ease-standard: cubic-bezier(0.2, 0, 0, 1)`
- `--ease-enter: cubic-bezier(0.16, 1, 0.3, 1)`
- `--ease-exit: cubic-bezier(0.4, 0, 1, 1)`

弹性效果只用于小型可点击元素，并用受控 cubic-bezier 近似；本期不为了 spring 单独引入动画依赖。

## 公开页面动效

### 公共导航

- 首次加载时仅做 180ms 淡入，不从顶部大幅滑入。
- 链接 hover 使用颜色和 1px 下划线或指示条过渡。
- 移动菜单从触发按钮附近以轻微缩放和淡入出现；关闭更快。
- 页面跳转使用 140–180ms 内容交叉淡化。导航本身保持稳定，避免整页闪烁。

### 首页

- Hero 眉题、标题、说明和按钮按 50–70ms 间隔分层出现；总时长不超过 600ms。
- 中央模型矩阵从中心向外错峰显现。模型图标 hover 上浮 3px，边框与阴影同时变化；不持续漂浮。
- 能力区块进入视口时上移 16px 并淡入，卡片错峰不超过 60ms。
- 卡片 hover 上浮 2px，内部图标缩放不超过 `1.04`。
- FAQ 展开使用内容高度过渡与图标旋转；折叠后焦点位置不跳动。
- CTA 只使用一次性背景明暗过渡，不加入循环光带。

### Models 列表与详情

- 模型卡片进入视口时淡入并上移 16px；每行错峰，不让长列表串行等待。
- hover 上浮 2px，封面图缩放至最多 `1.02`，厂商图标保持稳定。
- 搜索、筛选和排序后，现有卡片平滑淡出，结果重排后淡入；持续时间不超过 220ms。
- 价格档位切换采用数字交叉淡化，不做逐位滚轮动画，以免小数价格难读。
- xAI 短/长上下文切换的选中背景和指示条平滑移动。
- 详情页 Hero 与价格表按层级进入，说明文本不逐字播放。

### Docs 与静态公共页面

- Docs 侧栏当前项指示条以 160ms 平移到新条目。
- 锚点滚动使用浏览器平滑滚动；Reduced Motion 下立即定位。
- 代码复制按钮立即切换为成功状态，图标和文案交叉淡化，约 1.5 秒后恢复。
- 代码块、表格和长正文不做逐段滚动动画，保证阅读稳定。

## 普通用户看板动效

### 页面与数据加载

- 用户路由内容使用 140–180ms 淡化；侧栏和顶部导航不重复进入。
- Skeleton 使用低对比度、低频率 shimmer；Reduced Motion 下显示静态 skeleton。
- 数据加载完成后，卡片内容原位淡入，避免 skeleton 与真实内容高度不同导致跳动。
- 首屏核心统计数字只在首次真实加载时从旧值过渡到新值；路由返回或自动刷新时不从零重播。

### 图表与监控

- 折线图首次加载可进行 300–450ms 路径绘制或裁切揭示。
- 时间范围切换采用数据形态和透明度过渡，不清空整个图表再重建。
- 状态点只在状态刚发生变化时播放一次短脉冲；正常状态不持续闪烁。
- 自动刷新图标仅在请求期间旋转，请求结束立即停止。

### Keys、Payment 与表单

- 创建、复制、禁用和删除操作提供即时按钮反馈和 Toast 进入/退出。
- 复制成功使用图标与文案切换，不移动按钮位置。
- 表单校验信息在字段下方淡入，布局预留空间以减少跳动。
- 支付状态使用明确的处理中、成功或失败状态过渡；不使用无限庆祝动画。
- 危险操作弹窗保持克制，不加入弹跳或娱乐化效果。

### 表格与高密度区域

- 表格行 hover 只改变背景和边框，不抬升、不缩放。
- 排序图标与展开箭头使用 120–160ms 旋转或颜色反馈。
- 批量操作和分页切换不逐行播放进入动画。
- 管理员复用的表格组件默认不获得新增动效；普通用户页面通过显式属性启用必要反馈。

## 技术结构

### 全局层

- 在全局样式建立 motion tokens 与 Reduced Motion 覆盖。
- 建立少量命名 transition：`fade`、`fade-up`、`scale-fade`、`list-fade`。
- 路由切换由用户布局或公共布局显式启用，管理员布局不启用。

### 可复用层

- `useReducedMotion`：统一读取系统偏好，并对运行时变化作出响应。
- `useInViewReveal` 或等价指令：基于 `IntersectionObserver`，默认一次执行并在不可用时直接展示内容。
- `AnimatedNumber`：只用于少量核心统计，支持旧值到新值、格式化函数和 Reduced Motion。
- 现有 Vue `<Transition>` 优先复用，不为了简单过渡新增第三方包。

### 页面层

- 页面显式声明需要动效的元素和顺序，不能用全局选择器给所有 DOM 节点自动加动画。
- 列表动效有最大错峰数量；超出首屏部分直接使用相同时长，避免第 30 张卡片迟迟不出现。
- 图表优先使用现有图表库的更新动画能力，不额外叠加 DOM 动画。

## 性能与降级

- 动画不得延迟 API 调用、点击处理或首屏关键内容渲染。
- 禁止对大面积元素持续使用 `filter: blur()`、`box-shadow` 插值或未受控 `will-change`。
- `will-change` 只在确有需要的局部组件使用，并在动画结束后释放。
- 低端设备、后台标签页和 Reduced Motion 下禁用非必要动画。
- IntersectionObserver 不可用时直接显示最终状态。
- 动画 JS 加载失败时，内容必须默认可见、按钮和导航仍可使用。

## 验证标准

- 单元测试覆盖 Reduced Motion、Animated Number 更新、进入视口只执行一次和卸载清理。
- 组件测试覆盖筛选重排、复制成功、弹窗进入退出和加载状态切换。
- 路由测试断言公开布局和用户布局启用过渡，管理员布局没有新增页面动效。
- 桌面与移动端人工 QA 检查首屏、Models 筛选、Docs 复制、Dashboard 加载、图表刷新和用户 Monitor。
- 在 Reduced Motion 模式完整走一遍上述流程，确认没有依赖动画才能理解的状态。
- 检查无横向溢出、焦点丢失、点击延迟和动画期间不可点击的问题。
- 使用浏览器性能工具抽查首页和用户 Dashboard；目标是动画期间保持流畅，交互反馈无可感知延迟。

## 非目标

- 不重新设计 OwnAPI 的字体、色板、布局或品牌标识。
- 不为管理员后台添加动效。
- 不创建独立动画编辑器或运营配置系统。
- 不加入背景视频、Lottie、Rive、Three.js 或 WebGL。
- 不在本期自动生成新的营销图片；模型艺术图沿用当前资产策略。
