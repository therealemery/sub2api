# OwnAPI PackyAPI 文本与 DC-API MiniMax H3 上游接入设计

日期：2026-09-04  
状态：已获用户确认，待书面评审

## 目标

在 OwnAPI 控制台中配置并管理两个相互隔离的上游：

- PackyAPI：承载当前网站已展示的文本模型，例如 GPT、Claude、Gemini、GLM、Kimi 等。
- DC-API：独立承载 MiniMax H3 视频生成，不经过 PackyAPI，也不与 Packy 账号混用。

客户只创建和使用 OwnAPI API Key。OwnAPI 在服务端完成鉴权、模型权限检查、上游路由、用量记录和美元扣费，任何上游密钥都不会下发给客户。

## 范围

### 第一阶段

1. 后台账号管理支持录入、编辑、启用/停用 PackyAPI 和 DC-API 上游账号。
2. 文本模型请求通过现有 OpenAI 兼容网关转发到 PackyAPI。
3. MiniMax H3 视频请求通过独立 DC-API 适配器转发。
4. 复用现有 OwnAPI Key 鉴权、分组权限、余额和 USD 扣费逻辑。
5. 通过渠道/账号模型映射决定路由，不允许客户选择 Packy 分组或 DC-API 账号。

### 第二阶段

1. 用户侧视频生成页面：提示词、参考图、时长、分辨率及 DC-API 支持的其他参数。
2. 管理后台的视频模型映射、参数能力和价格配置便利入口。
3. 文本和视频上游成本、收入、利润的独立统计展示。

本设计不自动创建 Packy 或 DC-API 令牌，真实密钥只由管理员在控制台手动配置。

## 控制台配置

### 上游账号

扩展现有账号管理，不新增客户可见的密钥类型选择：

- `PackyAPI / <group>`：平台类型为 OpenAI 兼容文本上游，保存 Base URL、API Key、Packy 分组标识和精确模型白名单。
- `DC-API / minimax-h3`：平台类型为 DC-API 视频上游，保存 Base URL、API Key、模型标识和视频能力配置。

列表和详情接口继续对凭证脱敏；完整密钥只在服务端请求上游时使用。创建/编辑表单仅对管理员开放，并明确显示密钥不会转发给客户。

### 渠道和映射

- 文本渠道只绑定 PackyAPI 账号及其模型映射。
- 视频渠道只绑定 DC-API 账号及 `MiniMax H3` 模型映射。
- 映射必须是精确模型 ID；未知模型在请求到达上游前返回模型不可用错误。
- 文本与视频路由不可交叉绑定，避免 Packy 账号承接视频请求或 DC-API 账号承接文本请求。

## 请求与路由

### 文本模型

1. 客户将 OwnAPI Key 发送到现有 OpenAI 兼容文本端点。
2. 现有中间件验证 OwnAPI Key、分组、余额、配额、过期时间、IP 和速率限制。
3. 渠道按请求模型解析出唯一 PackyAPI 账号和上游模型 ID。
4. 转发时移除客户 Authorization，改用服务端保存的 PackyAPI Key。
5. 支持非流式和流式 Chat Completions；流式请求强制收集 usage。
6. 成功且有有效 usage 时，按 OwnAPI USD 价格扣费，并单独记录 Packy 成本。

### MiniMax H3 视频

1. 客户使用 OwnAPI Key 调用视频生成端点或 OwnAPI 视频接口。
2. 现有鉴权和分组权限检查先于上游请求执行。
3. 模型映射确认请求为 `MiniMax H3` 后，只选择 DC-API 视频账号。
4. DC-API 适配器按其接口要求转发提示词、参考图、时长、分辨率和其他已声明能力参数。
5. 客户请求中的 OwnAPI Key 永不发送给 DC-API；请求结果只返回经过清理的任务状态、任务 ID、媒体地址或错误。
6. 计费使用 OwnAPI 配置的美元价格，不使用 Packy 价格，也不让 DC-API 的原始计费格式改变客户扣费逻辑。

## 计费与成本

- 客户余额统一使用 USD。
- 文本模型客户价格沿用当前 OwnAPI 官方价格 × 0.7，并乘以客户 OwnAPI 分组/用户倍率。
- MiniMax H3 使用独立的 OwnAPI 视频价格配置和同一套客户倍率规则。
- PackyAPI 成本与 DC-API 成本分别写入上游成本记录，不能替代客户扣费。
- 失败、鉴权失败、限流、无有效用量或任务创建失败时不扣客户余额。
- 任务型视频接口在成功创建任务时记录请求；最终费用按已确认的计费事件或有效用量结算，不能根据不完整响应估算扣费。

## 安全要求

- PackyAPI Key 和 DC-API Key 只存储在后端账号凭证字段，不写入前端代码、文档、测试 fixture 或日志。
- API 返回、错误信息、截图和管理员列表均不得暴露完整上游密钥。
- 客户 OwnAPI Key 只用于 OwnAPI 鉴权，不转发到任何上游。
- 两个平台的账号、模型白名单、路由、健康状态和成本统计分开维护。
- 上游返回的原始错误正文经过清理后再返回客户；保留内部 request ID 供管理员排障。

## 失败与故障转移

- 未配置或无权限模型：在服务端返回 OpenAI 兼容的 model-not-available 错误。
- Packy/DC-API 返回 401/403：标记对应账号配置错误，不扣费。
- 返回 429：使用现有账号冷却/限流机制；没有可用账号时返回限流错误，不扣费。
- 可重试的 5xx 或网络故障：仅在存在同类型、同模型的备用账号时故障转移。
- 视频任务轮询或回调失败：记录任务失败和运维错误，不把上游凭证或原始响应暴露给客户。
- 用量持久化或扣费失败：沿用现有幂等、可追踪的强制计费路径，并记录运维事件。

## 验证

自动化测试覆盖：

- 管理员创建/编辑账号时凭证脱敏，非管理员不可访问配置接口。
- 文本模型只选 PackyAPI 账号，MiniMax H3 只选 DC-API 账号。
- OwnAPI Key 被接受并用于鉴权，但不会出现在上游请求 Authorization 中。
- 文本 Chat Completions 的流式和非流式转发及 usage 收集。
- 视频请求的提示词、参考图、时长、分辨率参数映射和响应清理。
- 客户 USD 扣费、账号成本记录、失败不扣费和幂等结算。
- `/v1/models` 或等效模型列表只返回当前 OwnAPI 分组可调用的模型。
- 现有非 Packy、非 DC-API 路由和支付/余额测试保持通过。

本地端到端测试使用低风险测试凭证；任何真实 Packy 或 DC-API Key 都只在用户确认后通过后台控制台配置，不提交到 Git。
